# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: treat people with respect, assume good faith, and keep discussion focused on the work.
Harassment of any kind is not welcome here, in issues, pull requests or anywhere else the project is
discussed.

Report unacceptable behavior to the maintainer at steven.p.gantz@gmail.com. Reports are handled
confidentially, and the maintainer will respond as promptly as circumstances allow.
